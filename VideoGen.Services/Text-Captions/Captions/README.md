# Captions

**Type:** `text-captions`

A basic text captions service for generated videos.

Captions takes a transcript's chapter text and burns timed captions into the
final video — keeping on-screen text in sync with the narration so videos
remain watchable with the sound off (the default on TikTok, Instagram, and
YouTube Shorts).

## Features

- Generates timed captions from transcript chapter text.
- Burns captions directly into the output video.
- Simple, readable default styling suited to short-form platforms.

## Notes

- Timing is derived from the transcript/TTS audio where available.
- Intentionally minimal — no fancy karaoke or animated word highlighting.
