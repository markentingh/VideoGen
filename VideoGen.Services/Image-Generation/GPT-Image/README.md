# GPT Image

**Type:** `image-generation`

Generates images through the OpenAI GPT Image 2.0 API.

The user configures their OpenAI API credentials once, and GPT Image produces
images from text prompts — thumbnails, scene stills, overlays, and other visual
assets used when composing videos.

## Features

- OpenAI API credential setup within the service settings.
- Prompt-based image generation via the GPT Image 2.0 API.
- Output images can feed the video generation and captions pipeline.

## Notes

- Requires a valid OpenAI API key with image generation access.
- API usage is billed by OpenAI under the user's own account.
