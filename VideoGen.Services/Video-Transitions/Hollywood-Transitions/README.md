# Hollywood Transitions

**Type:** `video-transitions`

Stitches together all of a project's videos into a single final cut, applying
cinematic transitions between each clip.

Hollywood Transitions takes the ordered set of clips in a project and renders a
continuous video, inserting polished transitions — cuts, fades, dissolves,
wipes, and other film-style moves — at each clip boundary.

## Features

- Concatenates project videos in sequence into one output video.
- Applies configurable transitions between every pair of adjacent clips.
- Transition styles inspired by classic Hollywood editing.

## Notes

- Runs after clip generation — it is the assembly step of the pipeline.
- Transition selection can be tuned per-project.
