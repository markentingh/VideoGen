# Local Videos

**Type:** `video-library`

Lets the user register one or more file system folders containing video files
that can be used as source assets when generating videos.

Local Videos indexes the configured folders and exposes the discovered clips to
other services (video generation, transitions, captions) so they can be pulled
into a project as b-roll, stock footage, or scene assets.

## Features

- Configure multiple local folders as video sources.
- Indexes supported video files in each folder for use as generation assets.
- Local-only: no uploads, no external services — assets stay on the file system.

## Notes

- Folders are configured by the user in the service settings.
- Intended as the asset pool that downstream services draw from.
